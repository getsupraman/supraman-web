Better together: how a shift runs

  1. Supraman starts the crew

    Each workspace gets its Claude Code sessions, in the background or in a tab. They come back after a restart.

  2. Agents write their work into Workman

    Sign in once, and every session Supraman launches gets its own Workman identity. Plans, tasks and evidence go to the record, not into files that go stale.

  3. You step in only where it counts

    The Inbox shows which sessions wait on you and which work items are blocked. Everything else keeps moving.

The loop every agent follows in Workman

^work_brief            # goal, rules, the next action
^work_next             # what is ready to start
^work_status in_progress
  … do the work …
^work_verify           # evidence, not a claim
^work_status done      # refused without proof

You don't type any of this. You say "Plan this feature", "Work the loop" or "Did we cheat?", and the agent makes the calls.

Get started

Supraman Windows 10/11 · x64

  1. Download the zip from GitHub Releases.
  2. Unblock it in the file's Properties, then extract it anywhere. There's no installer; SmartScreen may ask once.
  3. Run supraman.exe and add a folder of your repos as a workspace.

Needs the Claude Code CLI 2.1.308 or newer, and PowerShell 7 for terminal tabs. It updates itself with signed releases.

Download Supraman

Workman any Claude Code

Connect to the hosted server (invite only for now). You sign in in the browser, so there's no token to paste:

claude mcp add --transport http --scope user \
  workman https://work.supraman.ai/mcp

Then add the skills in Claude Code:

/plugin marketplace add getsupraman/workman
/plugin install workman@supraman

Want to self-host? Run /workman:setup. It starts Workman in Docker on your machine.
