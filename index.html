One above the crew, a crew that does the work

Every tool carries the same chevron. Supraman stands above the crew; the others are the crew's tools.

Supraman

A desktop app that supervises workspaces of Claude Code sessions. It launches, resumes and watches them, and shows you which ones need you.

Workman

A self-hosted MCP server and dashboard that records what agents do: projects, runs, tasks, evidence and decisions. Your agents stop writing PLAN.md files.

How a shift runs

  1. Supraman starts the crew

    Each workspace gets its Claude Code sessions. They run in the background and come back after a restart.

  2. Agents write their work into Workman

    Plans, tasks, findings and the evidence for each one go into Workman over MCP, not into files that go stale.

  3. You step in where it counts

    Supraman shows which sessions are blocked or waiting on you. Workman's dashboard shows where every run stands.

The loop every agent follows in Workman

^work_brief            # goal, rules, the next action
^work_next             # what is ready to start
^work_status in_progress
  … do the work …
^work_verify           # evidence the agent ran itself
^work_status done      # refused without evidence

Closing is guarded. Workman refuses done until every criterion is checked, a verification exists and no blocker is open. Work can't be dropped quietly: deferring moves it somewhere real.

Open source, self-hosted, yours

Supraman and Workman are being prepared for release under Apache-2.0. Workman runs on your own machine or server, and your work records stay there.
